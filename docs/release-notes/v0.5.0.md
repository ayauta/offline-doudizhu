# 单机斗地主 v0.5.0

第五个公开预览版。这一版把「高手」档的电脑对手整体换强：地主换了新策略，农民沿用
此前已经验证过的强化策略。

## 变化

- **「高手」档的地主变强了。** 地主现在从一个 403 维局面-动作模型里，对**全部合法
  出牌**逐一打分再选最好的一手，而不是只在少数几个候选里挑。这一改动在完全独立的
  新牌局上做过验证，并在真机上确认过响应速度。
- **「高手」档的农民继续使用此前验证过的强化策略**，本次未改动。
- **AI 整体对局能力进一步提升**：地主与农民两侧现在都是各自验证过的最强策略。
- **快了很多，而且更稳。** 地主的决策时间在真机（小米 10S）上 p99 约 92 ms、
  最坏约 95 ms，远低于 480 ms 的响应预算；此前的地主策略最坏要 108 ms 且波动更大。

## 保持不变

- **完全离线**：没有账号、没有广告、不联网。AI 模型随安装包一起发布，运行时不做
  任何网络请求。
- **「休闲」和「默认」两档没有改动。** 想轻松玩仍然选这两档，它们的行为和上一版
  完全一致。
- 规则、发牌、界面、操作方式均未改动。

## 技术说明（面向开发者与研究者）

本次发布的 AI 配置代号 **AI-v2**，取代此前的 AI-v1：

| | 策略 | 模型标识 |
| --- | --- | --- |
| 地主 | full-action LightGBM 策略（研究代号 CHEAP，403 列 schema，512 棵树） | `070f5b0b728176a8…` |
| 农民 | π1 counterfactual selector | `010a8a4a00524f06…`，阈值 0.01 |

- **仅作用于「高手」档。** 「休闲」「默认」两档的策略与上一版逐字节相同。
- **强度证据**（均为独立验证，不可跨 benchmark 相加）：
  - 地主，对 π1/π1 农民：+9.400pp，95% CI [+8.038, +10.762]
  - 地主，对 default/default 农民：+3.450pp，95% CI [+2.059, +4.841]
  - 农民 π1：Spec 063 最终验证
- **真机确认**：小米 10S（Android 11 / SDK 30），走真实产品 Worker 的 152 个地主
  决策，执行动作与参考实现 0 分歧，0 次超时回退，策略保留率 100%。
- **体积**：「高手」档的 AI worker（含模型）gzip 后约 562 KiB，仍远小于 650 KiB 的
  预算上限。
