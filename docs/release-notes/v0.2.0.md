# 单机斗地主 v0.2.0

第二个公开预览版。主要变化是电脑水平可以选了：新增三档更强的本地 AI，
并把水平选择放到了首页。

## 新增

- **四档电脑水平：休闲、默认、高手、大师。** 默认档保持原有策略不变；
  三档增强水平都是纯规则算法，只读取脱敏后的牌局视图，看不到对手手牌。
- **首页内联水平选择。** 四个分段直接显示在「开始游戏」下方，点一下即生效
  并立即保存，没有弹窗、没有确认按钮。

## 修复

- **「本局已使用默认水平」这句话以前是不准的。** 旧实现在任何失败时都这样
  提示，但实际上只降级了当前这一手，下一手仍然会去请求你选的档位。现在：
  - 环境级失败（Worker 建不起来或崩了）→ 本局剩余对局使用默认水平，
    如实提示一次，下一局自动重试你选的档位；
  - 单次失败（超时、迟到、返回非法出牌）→ 只这一手静默降级，不打扰你。
- 修复了首页在样式表到达前显示**整屏白纸**的问题：现在首帧就是牌桌的深绿
  底色。
- 修复了每次加载都会请求 `/favicon.ico` 并返回 404 的问题。

## 保持不变

- 无账号、广告、付费、统计、遥测、远程配置或业务 API；
- Android 从第一次启动起完全离线；PWA 安装后离线可用；
- 默认档 AI 与「提示」仍在原有同步路径上，未做改动；
- 存档格式未变，从 v0.1.0 升级不需要迁移。

## 下载

Android 用户下载 `offline-doudizhu-v0.2.0-android.apk`。这是未上架应用商店的
直接安装包，安装时 Android 会要求确认未知来源。旁边的 `.sha256` 文件用于
校验下载完整性。

已安装 v0.1.0 的用户可以直接覆盖安装：本次仍使用首次公开发布时的同一签名
证书，签名证书 SHA-256 指纹保持为：
`8C:19:4B:EA:92:D4:38:85:93:60:D0:21:95:A5:83:4F:9E:45:62:26:A5:0B:9B:75:70:45:16:F0:13:F6:22:3D`。

## 已知限制

- 暂无游戏内规则查看器；
- 退出或重载后不会恢复未完成的牌局；
- 暂无声音；
- 这是 Pre-release，不代表兼容性和界面已经达到 `v1.0` 稳定承诺。
