# 单机斗地主 v0.4.0

第四个公开预览版。这一版主要修一个「在老安卓手机上玩不了」的问题，外加一处手感修正。

## 变化

- **修好了 Android 11 / 系统 WebView 90 上「划过手牌只选中一张」。** 之前在这类
  设备上，手指横着划过一排手牌，只有起点那一张会被切换，中间划过的牌全都漏掉——
  等于没法正常选牌。原因是源码用了一个新版浏览器才有的语法：WebView 90 上它会
  直接抛错，让整个选牌处理从第二个触摸事件起就失效。已经改成等价的老写法。
  顺手把同类问题一并清理：出牌后的手牌重排动画、以及 AI 路径上的一处同类写法。
- **长按牌桌不再选中界面文字。** 之前从牌桌按住再拖到旁边的按钮，会把按钮上的
  字一起选中；在手机上还会带出系统的复制浮条，盖在牌桌上。现在整个应用范围内
  的文字都不再可选中——界面里全是按钮和状态文字，没有需要复制的内容。
- **新增运行时兼容门禁。** 上面那类「用了新浏览器才有的语法」的问题，以后在
  提交阶段就会被拦下来，不会再等到真机上才发现。同时新增一条真机探测命令，
  用于在连接的安卓设备上核对运行时的实际能力与划选行为。

## 保持不变

- 三档 AI（休闲、默认、高手）与「提示」的行为未改动；
- 无账号、广告、付费、统计、遥测、远程配置或业务 API；
- Android 从第一次启动起完全离线；PWA 安装后离线可用；
- 存档格式未变，从 v0.3.0 升级不需要迁移；
- 界面布局、牌桌与手牌手感未改动。

## 下载

Android 用户下载 `offline-doudizhu-v0.4.0-android.apk`。这是未上架应用商店的
直接安装包，安装时 Android 会要求确认未知来源。旁边的 `.sha256` 文件用于
校验下载完整性。

已安装 v0.3.0 的用户可以直接覆盖安装：本次仍使用首次公开发布时的同一签名
证书，签名证书 SHA-256 指纹保持为：
`8C:19:4B:EA:92:D4:38:85:93:60:D0:21:95:A5:83:4F:9E:45:62:26:A5:0B:9B:75:70:45:16:F0:13:F6:22:3D`。

## 已知限制

- 暂无游戏内规则查看器；
- 退出或重载后不会恢复未完成的牌局；
- 暂无声音；
- 游戏内的文字无法选中；
- 「划过手牌」的修复在 Android 11 / WebView 90 上已实测通过，但触摸舒适度、
  两种横屏握持与发热仍以真人试玩为准，不属于自动化验证的结论；
- 这是 Pre-release，不代表兼容性和界面已经达到 `v1.0` 稳定承诺。
