# 单机斗地主 v0.3.0

第三个公开预览版。变化集中在一件事：**「高手」这一档真的变强了。**

## 变化

- **「高手」与「大师」合并为一档。** 原来的「大师」是四档里唯一被测量证明
  强于「默认」的档位，但它和「高手」长期并存、区分度很小，两条维护路径换来
  的收益不成比例。现在只剩三档——休闲、默认、高手——「高手」用的就是原来
  那套最强的搜索实现。
- **「高手」的出招按目标手机重新定过规模。** 原来的推演规模在手机上跑不完，
  会被预算截断到只剩零头；现在一次决策在手机上约 50 ms 完成，绝大多数情况
  远低于等待上限，而且**棋力没有因此下降**（见下）。
- **棋力有实测支撑。** 与「默认」对局 400 副、2400 局，「高手」胜率 **53.2%**
  （95% 区间 51.9%–54.5%）。这不是"感觉更强"，是量出来的。

## 保持不变

- 默认档 AI 与「提示」完全未改动，仍在原来的同步路径上；
- 无账号、广告、付费、统计、遥测、远程配置或业务 API；
- Android 从第一次启动起完全离线；PWA 安装后离线可用；
- 存档格式未变，从 v0.2.0 升级不需要迁移。

## 下载

Android 用户下载 `offline-doudizhu-v0.3.0-android.apk`。这是未上架应用商店的
直接安装包，安装时 Android 会要求确认未知来源。旁边的 `.sha256` 文件用于
校验下载完整性。

已安装 v0.2.0 的用户可以直接覆盖安装：本次仍使用首次公开发布时的同一签名
证书，签名证书 SHA-256 指纹保持为：
`8C:19:4B:EA:92:D4:38:85:93:60:D0:21:95:A5:83:4F:9E:45:62:26:A5:0B:9B:75:70:45:16:F0:13:F6:22:3D`。

## 已知限制

- 暂无游戏内规则查看器；
- 退出或重载后不会恢复未完成的牌局；
- 暂无声音；
- 「高手」的棋力只在机器对战里量过；真人上手是否觉得"明显更难"仍以试玩为准；
- 这是 Pre-release，不代表兼容性和界面已经达到 `v1.0` 稳定承诺。
