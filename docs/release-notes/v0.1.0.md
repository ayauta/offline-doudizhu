# 单机斗地主 v0.1.0

这是第一个公开预览版，适合体验和家庭使用。

## 可以做什么

- 一名真人玩家与两名本地 AI 完成完整斗地主牌局；
- 支持经典牌型、提示、不出、不合法原因和胜负重开；
- Android 10+ 安装后从第一次启动起无需网络；
- Web/PWA 可以在线打开，安装缓存后离线使用；
- 无账号、广告、付费、统计、遥测、远程配置或业务 API。

## 下载

Android 用户下载 `offline-doudizhu-v0.1.0-android.apk`。这是未上架应用商店的
直接安装包，安装时 Android 会要求确认未知来源。旁边的 `.sha256` 文件用于
校验下载完整性。

正式 APK 的签名证书 SHA-256 指纹为：
`8C:19:4B:EA:92:D4:38:85:93:60:D0:21:95:A5:83:4F:9E:45:62:26:A5:0B:9B:75:70:45:16:F0:13:F6:22:3D`。

## 已知限制

- 暂无游戏内规则查看器；
- 暂不恢复被关闭或重载的未完成牌局；
- 暂无声音和 AI 难度选项；
- 这是 Pre-release，欢迎先以体验版预期使用。
