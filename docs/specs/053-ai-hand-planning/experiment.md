# 实验结果：合法拆分上界未证实提升棋力

日期：2026-09-12。执行规格：Spec 053。

## 决定

**撤回本次生产改动，保留实验补丁、测试和逐副数据。**
估计的数学性质改善了，但发现集没有证实棋力收益；不能据此发布更强档位。
默认档的家长试玩反馈继续作为产品基准，首次默认选择不变。

这次只研究一项增强能力，不减少档位，不修改轻松档、默认档、提示、
界面、520 ms 节拍、480 ms 窗口、节点预算、搜索深度或评分权重。

## 唯一变量与先红后绿

在增强档 `createHandAnalyzer` 内，把搜索初值和节点耗尽时的返回值，
从可能低估的快速启发式改成可行拆分上界：每个点数先单独一组，再把
不同单张／对子组分配给不同三张组作附件，不重复计算序列节省。
`estimateBasicHandTurns` 保持原样。候选只改一个生产文件，13 行新增、
2 行删除；无新依赖或策略模块。

修复前五个测试全部失败：

- `3334445`：实际至少 2 手，得到 1；
- `3334455`：实际至少 2 手，得到 1；
- `33344556`：实际至少 3 手，得到 1；
- 小手牌穷举参照：1 节点预算也低估；
- 前一手牌耗尽共享节点预算后，再次分析仍然低估。

修复后五项全部通过；与原有增强策略、默认策略和请求处理测试合跑，
共 34 项通过，原有断言没有放宽。独立参照枚举引擎生成的合法划分，
不使用生产启发式剪枝；覆盖 3–6 四个点数、各 0–3 张、总数不超过 9 的
全部组合，测试 1/2/16 节点时不低估，以及 10,000 节点时的精确性。
这证明有限测试域上的契约，不是所有 20 张手牌上的最优性证明。

完整生产改动和五项测试保存在 `candidate.patch`；撤回后没有把这些
要求未采用契约的测试留在日常门禁中，也没有新增“正确答案应该是 1”的测试。

## 复现

在未修改的出厂 `hand-analyzer.ts` 上，先记录基线；再检查并应用
`candidate.patch`，用相同环境和种子重跑。补丁包含新的测试文件：

```bash
source scripts/activate-toolchain.sh
pnpm exec vitest run tests/core/hand-planning.test.ts \
  tests/core/enhanced-ai.test.ts tests/core/casual-ai.test.ts \
  tests/app/ai-decision-handler.test.ts

AI_BENCH_PAIRS=default:expert,casual:default AI_BENCH_DEALS=400 \
AI_BENCH_SECONDS=180 AI_BENCH_SEED=301 AI_BENCH_UNBOUNDED_EVERY=10 \
pnpm bench:ai -t 'over mirrored deals'
```

采集逐副数据无需改生产代码：临时 Vitest 包装器调用
`runPairTournament(readConfig(), stronger, weaker, recorder, { quiet: true })`，
保存返回值的 `perDealA`、`perDealB`；用 `createRecorder({ logCommands: true })`
取得命令日志。摘要是 `sha256(JSON.stringify(recorder.commands))`。
本轮包装器和原始日志在 `/tmp/ai-planning-20260912-xwy06ycw/`，
仓库中的 JSON 和补丁是持久研究证据，不依赖该临时目录存在。

重算配对区间时，对每副牌 i 计算：
`((candidateA[i] + candidateB[i]) - (baselineA[i] + baselineB[i])) / 6`，
再将整个差值向量传给 `clusterInterval`。分臂则分别除以 3。
真实墙钟预算可能造成少量决策差异，不保证每次命令摘要都逐位复现；
未使用真实对手手牌来选择任何动作。

## 对下一步的约束

最终已恢复原生产实现；`pnpm check` 通过 265 项确定性测试和 30 个
Chromium 场景，以及构建、Android 静态交付、边界、隐私与体积检查。
沙箱首次阻止本地连接，放行本地服务／浏览器后同一完整命令通过。
另行通过基座的统计、单强座位、确定性／world-cap 三项自检。
最终 gzip 体积仍为 main 19.67 KiB、CSS 5.32 KiB、worker 8.16 KiB。
没有真机试玩、发布或提交。

本结果否决的是“直接用保守合法拆分上界替换现有估计，就足以增强棋力”。
没有证明拆牌规划无用，也没有证明这个更保守的估计更差。
它可能高估预算不足时的序列价值，现有评分权重也可能与旧估计相互适应；
这些只是解释假设，不作为本轮继续改权重的理由。

下一个独立实验应先采集旧／新高手实际分歧的局面，检查它们是否更好地
安排了后续出牌权与配合，再决定需要改评估语义还是搜索方法。
不要根据 +0.75 个点的点估计宣称档位已经分开。
