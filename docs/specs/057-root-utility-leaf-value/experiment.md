## calibration corpus 的形状

采集条件：designed 路径、种子 5001–5400（即 `AI_BENCH_SEED=0` +
`AI_BENCH_DEAL_START=5001..5400`）、8 路并行。

| 指标 | 值 |
| --- | --- |
| 牌局 | 400（5001–5400，gaps=0 overlaps=0） |
| 决策 | 25,684（每副 27–104，中位 64） |
| 叶 | 429,504（其中终局叶 43,726） |
| 候选数 < 3 的决策 | **13,704（53.4%）** |
| 采集 wall-clock | 约 3 分钟（8 路） |
| **离线重放 wall-clock** | **9.6 秒** |
| 保真度自检 | **0/25,684** 与记录选择不符 |

两条形状结论：

1. **超过一半的决策候选数不足 3**（合法动作只有 1–2 个），搜索在那部分局面上
   本就没有选择余地。这既是 E1 effect gate 的分母，也是 E3 扩候选时要面对的
   上限。
2. **前两名候选的专家分常常只差 1 分**（例：`[2745, 2744, 2585]`）。先验的
   160 分差经常恰好被原始分抵消，所以 rollout 的实际话语权**大于**早先按
   「160 分先验 vs ±30 影响力」做的估算。这与 4.3% 的推翻率相符。

**语料为什么在插桩还原后仍然有效**：重放自检用出货 evaluator 在完全相同的叶子上
重放，25,684 个决策全部落到记录的选择上。这条自检同时钉住阵营划分、终局处理、
混合权重 0.2 与平手规则——重放链忠实，语料才可比。

## newEvaluator v1：三个门槛

实现：`src/core/ai/hand-turns.ts` —— 「给定一手牌，最少能拆成几手打完」。不含牌权、
威胁、队友、控制牌或任何权重；除了"手数怎么算"以外不改任何东西。
测试：`tests/core/hand-turns.test.ts`。

### Correctness gate：通过

- 已知反例：`3334445` → 2、`3334455` → 2、`33344556` → 3（旧估计给 1）。
- **与引擎逐条对齐**：对约 380 手牌（随机 1–14 张 + 结构化手牌）比较本模块枚举的
  走法与 `generateLegalActions` 的合法走法，要求集合完全相等。
- 该门禁经反向验证会变红：打掉「最小点作为更高飞机翅膀」分支 → 2 项红；
  放开「大小王同翅」→ 3 项红（第一次只红 2 项，暴露了等价性语料漏掉大小王同翅
  这一族，已补 5 手结构化手牌）。
- 边界：翅膀可从同一张点取两张（`33344455` 是一手，引擎同此），大小王同翅被拒
  （`333444wW` 是两手）。

## 效应量级的算术（不是门槛，是预期）

登记里禁止用分歧率代替棋力，也禁止设最低翻转率门槛。以下只是一个**带假设的比例
推算**，供决定是否值得动用 E1-A 的预算，不构成采纳判据。

- 出厂 rollout 在 **4.3%** 的决策上推翻专家首选，而它相对专家档的收益约 **+3.5pp**
  （专家档对默认 49.6%，大师档 53.2%）。
- E1 改变 **0.7%** 的决策，是出厂 rollout 改动量的 1/6。
- 若被改动的决策质量与出厂 rollout 的改动相当，按比例得 **≈ +0.6pp**；这是上限，
  且权重 ×10 实验（53.2% → 48.9%）说明"更多地听 rollout 的"并不自动更好。
- SESOI = 1.0pp。**预期效应低于 SESOI。**
