## calibration corpus 的形状

采集条件：designed 路径、种子 5001–5400（即 `AI_BENCH_SEED=0` +
`AI_BENCH_DEAL_START=5001..5400`）、8 路并行。

| 指标 | 值 |
| --- | --- |
| 牌局 | 400（5001–5400，gaps=0 overlaps=0） |
| 决策 | 25,684（每副 27–104，中位 64） |
| 叶 | 429,504（其中终局叶 43,726） |
| 候选数 < 3 的决策 | **13,704（53.4%）** |
| 采集 wall-clock | 约 3 分钟（8 路） |
| **离线重放 wall-clock** | **9.6 秒** |
| 保真度自检 | **0/25,684** 与记录选择不符 |

两条形状结论：

1. **超过一半的决策候选数不足 3**（合法动作只有 1–2 个），搜索在那部分局面上
   本就没有选择余地。这既是 E1 effect gate 的分母，也是 E3 扩候选时要面对的
   上限。
2. **前两名候选的专家分常常只差 1 分**（例：`[2745, 2744, 2585]`）。先验的
   160 分差经常恰好被原始分抵消，所以 rollout 的实际话语权**大于**早先按
   「160 分先验 vs ±30 影响力」做的估算。这与 4.3% 的推翻率相符。

**语料为什么在插桩还原后仍然有效**：重放自检用出货 evaluator 在完全相同的叶子上
重放，25,684 个决策全部落到记录的选择上。这条自检同时钉住阵营划分、终局处理、
混合权重 0.2 与平手规则——重放链忠实，语料才可比。

## Step 1（shipped 基线）与两处更正

8-world 出货配置实测，用于回答「旧数字是否还成立」：

| 指标 | 8-world 实测 | 记录中的旧值 | 结论 |
| --- | --- | --- | --- |
| master 预算截断率 | **0.8% [0.4%, 1.4%]**（n=1313） | 22.4% | 旧值是 32-world 的，**作废** |
| 完成 world 数 | p50 = p10 = p90 = **8.0**；预检跳过 0、根排序截断 0 | — | 预算几乎总能跑满设计工作量 |
| rollout 推翻专家首选 | **4.3%（56/1313）** | 6.9%（12/174） | 旧值同样是 32-world 且样本小一个量级，**作废** |

复跑确定性（决策级，2.2 万决策）：

| 对比 | 命令分歧 | 截断标记不同的决策 |
| --- | --- | --- |
| designed ×2 | **0** | 0 |
| shipped ×2 | **0** | 7 |
| shipped vs designed | 首次分歧在第 **#6453** 个决策 | — |

首次分歧是一次截断事件的现场：shipped 跑 126.70ms / `cut=true` / 14 polls / 出单张，
designed 跑 198.03ms / `cut=false` / 15 polls / 过牌。**少跑一个 world 就翻了向。**
此前约 49 次截断里只有这 1 次改变了出招，传播率约 2%。之后状态分叉，所以那
69.6% 的"分歧"是级联，不是 15,409 个独立事件。

### 更正二：地主臂的「跌破 50%」是样本假象

Step 1 的 shipped 配对撞 600s 软上限，只跑了 202/400 副，得到地主臂 49.8%。
400 副 designed 下是 **51.7% [49.0%, 54.3]**。n=202 时 CI 约 ±3.65pp，当时的
点估计低于 50% 是抽样波动，不是发现。
